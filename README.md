# email-assets

Публичное хранилище картинок для HTML-писем. Раздаётся через jsDelivr CDN.

Одна папка — один заказ:

```
email-assets/
├── demo/        # картинки демо-шаблона среды
└── <заказ>/     # картинки конкретного письма
```

Ссылка на файл:

```
https://cdn.jsdelivr.net/gh/yakupjoraev/email-assets@main/<заказ>/<файл>.png
```

Базовая ссылка прописывается в `PUBLIC_ASSET_BASE_URL` в `.env` проекта вёрстки.

## Правила

1. **Только PNG, JPEG и GIF.** SVG и WebP в письмах не работают.
2. **Не перезаливать файл под тем же именем** — jsDelivr держит его в кэше до недели.
   Обновил картинку → новое имя (`logo-2.png`).
3. **Папку заказа нельзя удалять сразу после сдачи.** Если заказчик успел разослать письмо
   с этими ссылками, удаление сломает картинки у всех получателей. Удалять можно только
   убедившись, что в рассылке стоят ссылки заказчика.
4. **Ничего конфиденциального.** Репозиторий публичный: макеты акций до старта,
   персональные данные и внутренние материалы сюда не кладём.
